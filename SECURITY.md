# Security Policy

## Supported Versions

Only the latest stable release of AutoType receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in AutoType, please report it privately rather than opening a public issue.

- **Private Reporting**: Please use GitHub's private vulnerability reporting feature at:
  https://github.com/premtechworks/AutoType-Linux/security/advisories/new
- **Alternative Contact**: If you need an alternative contact method, please reach out to [Security Team](mailto:premtechworks@gmail.com).
- Include detailed reproduction steps and affected components.
- You should receive an acknowledgment within 48 hours.
